# MATLAB spectra (legacy)

Output of `legacy/current2HHG.m`, kept for reference. The current analysis is done by the `hhg` package; see the main README.

Tab-separated columns:

| Column | Content |
|---|---|
| 1 | photon energy (eV) |
| 2 | sum over x, y, z of \|J(w)\|^2 |
| 3 | column 2 times energy^2 (the HHG spectrum) |
| 4-6 | x, y and z parts of column 3 |

| File | Source run |
|---|---|
| `HHG_cp_I=1.5e12.out` | collinear, 1.5e12 W/cm^2 |
| `HHG_lp_I=1.5e12.out` | linear, 1.5e12 W/cm^2 |
| `HHG_total_current.out` | not recorded |
